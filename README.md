# Nocturne Firewatch — тема для Shikimori

Основной файл для установки — [shikimori-nocturne-dossier.css](./shikimori-nocturne-dossier.css) (около 85 700 символов, все CSS-блоки закрыты). Это полная версия темы с актуальной раскладкой «Личного досье», переработанным списком аниме и общими фоновыми правилами. Новая раскладка верхнего профиля ограничена(!) профилем `d1n0tf` (`data-user-id="1197767"`); остальные правила применяются к соответствующим страницам сайта.

## Установка

1. Откройте в Shikimori **Настройки → Внешний вид сайта → Пользовательский CSS**.
2. Полностью замените содержимое редактора содержимым `shikimori-nocturne-dossier.css`.
3. Вставляйте только CSS: не добавляйте `<style id="custom_css">` и `</style>` — этот контейнер Shikimori создаёт сам.
4. Сохраните стиль, откройте [сброс кэша стилей](https://shikimori.io/tests/reset_styles_cache), затем обновите страницу через `Ctrl+F5`.

## Что исправлено

- скрыт scrollbar без отключения прокрутки;
- убраны серые фоны кнопок верхнего меню и заменена стрелка профиля на аккуратное состояние меню;
- выровнены по высоте карточки шапки профиля, убран лишний вертикальный зазор;
- верхний блок «Личное досье» пересобран в ровную трёхзонную сетку с отдельными зонами профиля, статистики и истории;
- блок друзей собран в компактную сетку круглых аватаров;
- убрана розовая подсветка над внутренними блоками друзей и клубов;
- длинные подписи, история, служебные значения и строка с информацией профиля обрезаются аккуратным ellipsis без случайных переносов;
- блок статистики «Список аниме» переделан в лёгкую панель с тремя числовыми зонами, подписями и нижней строкой статусов;
- даты на графике активности помещены внутрь контейнера;
- страница полного списка аниме (`p-user_rates-index`) получила отдельную карточную раскладку, поиск, фильтры и таблицу без резких стандартных серых панелей;
- основные страницы получили тёмный фон с указанным изображением:
  [background-hq.webp](https://shikimatch.com/shared/dark/background-hq.webp).

Фон затемнён градиентом для читаемости, а на мобильной ширине переключается на обычный (не фиксированный) режим.
